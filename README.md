# 🌱 Smart Agricultural Techniques Website

## 📖 Project Description

This project is a **static educational website** designed to showcase **modern and smart agricultural techniques** used around the world, with a strong focus on **European farming methods** and **sustainable agriculture**.

The website provides information on:
- Advanced farming technologies
- Soil, water, and pest management
- Benefits of modern agriculture
- Farmer education and awareness

It is suitable for **students, farmers, and agricultural researchers**.

---

## ✨ Features

- 📌 Multi-section navigation (Home, About, More, Information, Output)
- 🌾 Detailed explanation of modern agriculture techniques
- 🎥 Embedded YouTube video on smart farming
- 🖼️ Image galleries for visual learning
- 🎶 Animated background (music-style falling icons)
- 🧑‍🌾 Farmer-related quotes
- 🔐 Login form UI (frontend only)
- 📊 Data table showing agricultural export values
- 📱 Responsive layout (viewport enabled)

---

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling, layout, and animations
- **JavaScript** – Interactivity (date & time display)
- **YouTube Embed** – Educational video content
